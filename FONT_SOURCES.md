# Typography

Reference: [Kave Home sofa collection](https://kavehome.com/es/es/o/sofas), inspected with Firecrawl on 30 October 2026. The page branding identifies Poppins alongside the custom Kave-Haffer / Kave-HafferText families.

MAISONNE uses **Poppins** in regular (400), medium (500) and semibold (600) weights for a consistent sans-serif interface. The files are served from `public/fonts/` with `font-display: swap`; the regular weight is preloaded. No external font request is needed at runtime.

Font source: [Google Fonts — Poppins](https://fonts.google.com/specimen/Poppins). Copyright and the SIL Open Font License are included in [public/fonts/Poppins-OFL.txt](public/fonts/Poppins-OFL.txt).
